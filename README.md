# Tello Connect

ルーター接続（station mode）のTello EDUを自動で見つけ、4桁の合言葉で相手とマッチングし、2台同時にバトルさせて勝ち負けを判定するWebアプリです。

## 起動

Python 3.10以上が必要です。遊ぶPCそれぞれで動かします（サーバーに置くものではありません。TelloにはPCと同じWi-Fiの中からしか命令が届かないためです）。

```sh
git clone https://github.com/u-shin16/drone-fight.git
cd drone-fight
python3 -m pip install -r requirements.txt
python3 app.py
```

ブラウザで http://127.0.0.1:5050 を開きます。終了はターミナルで Ctrl+C です（飛行中なら着陸します）。

「自分のファイル」には、このフォルダと同じ階層の `Tello-Python/Single_Tello_Test/*.txt` が出ます（なければ空です）。

## できること

- **ドローンを探す**: 同じネットワーク（/24）の各アドレスに無害なパケット（ポート9）を送ってARPを埋め、MACアドレスの先頭がTelloのもの（`48:1c:b9` `34:d2:62` `60:60:1f`）を一覧にします。Telloは最初に `command` を送ってきたPCにしか返事をしないため、探すときはTelloに何も送りません。「自分の機体にする」を押したドローンにだけ `command` を送り、電池を確認します。
- **名前を覚える**: Wi-Fi名（`TELLO-` ＋MACの下6桁）ごとに名前を `drones.json` に保存します。IPが変わっても同じ機体として表示されます。
- **安全**: 127.0.0.1でだけ待ち受け、Host・Originが違う要求とJSON以外のPOSTを拒否します（ほかのWebサイトから操作させない）。
- **マッチング（2の画面）**: プレイヤー名・自分のドローン・4桁の合言葉を入れて「マッチング開始」を押すと、同じ合言葉でマッチング中のPCとマッチします。合言葉はハッシュにしてUDPブロードキャスト（ポート47474）で送ります。名前・ドローン・合言葉は `settings.json` に保存します。
- **バトル（3の画面）**: 作戦を「モード」（`modes/` の攻め（闘牛スタイル：相手の高さに合わせて3m突進→振り返ってまた突進）・逃げ・守り・回避。終わるまでくり返す。`match_height` は相手の今の高さに合わせるこのアプリ独自の命令）か「自分のファイル」（`Tello-Python/Single_Tello_Test/*.txt` を1回実行し、その後ホバリング）から選び、2人とも準備OKで5秒後に同時離陸します。バトル中もモードを切り替えられ、降参（Esc）・緊急停止ボタンがあります。
- **作戦ファイル（上の「作戦ファイル」）**: 自分で作戦を書いて保存できます（`plans/` に保存、GitHubには例だけ）。書いている間に命令の誤りと「一番遠くて何cm行くか」「1周で元の位置から何cmずれるか」を表示します。`repeat` の行（「最後まで行ったらくり返す」）があるとバトル中くり返し、1周で50cm以上ずれるファイルはくり返せません。バトル画面の「自分のファイル」で選ぶだけで使えます。
- **判定**: Telloの状態（ポート8890の `h`・`tof`）で地面にいる時間が1秒続いたら「落ちた」とし、最後まで飛んでいた方が勝ち。1秒以内なら引き分け、制限時間60秒で引き分け、離陸できなければ負け。勝負がつくと勝った方も自動で着陸します。
- **電池**: Telloが送ってくる状態（ポート8890）を常に受け取り、自分の機体の電池をリアルタイムで表示し、相手にも送ります。
- **安全**: 高さ合わせは移動後の新しい高さでしか行わず180cmより上には上がらない、電池30%未満は離陸しない、エラー3回で着陸、`delay` 中も5秒ごとに通信して自動着陸を防ぐ、アプリ終了時に着陸。モードは1周で元の位置に戻ります。
- **ルーターにつなぐ設定**: TelloのWi-Fiに直接つないでいるときだけ、`ap <Wi-Fi名> <パスワード>` を送ります。

## 注意

- 学校などのWi-Fiで端末どうしの通信が遮断されていると、ドローンも相手のPCも見つかりません。
- ルーター接続のTelloは映像を送らないため、`drone_fight/fight.py`（カメラで相手を探す方式）は使えません。
